1. Последовательность в файле `sequence.fasta`. Программы предсказатели: ESMFold, OpenFold. Программа выравниватель: MMLigner.
2. Полученные ноутбуки с предсказанной структурой (формат \*.ipynb) в файлах `ESMFold_copy.ipynb`, `OpenFold_copy.ipynb`.
3. Полученные предсказания структур в формате PDB в файлах `esmfold.pdb`, `openfold.pdb`.
4. Полная выдача программы выравнивания MMLigner (запсукался в WSL из-за недоступности веб-версии) в папке `/alignment`.
5. Визулизация и раскрашивание выполнены в https://www.rcsb.org/3d-view/. Результаты в папке `/visualization`.
6. Краткие выводы в файле `report.md`.
